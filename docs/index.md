# tempo-virtual-zarr-pipeline

Virtual Zarr / Icechunk stores for the TEMPO Level 3 gridded products hosted at
NASA ASDC (`TEMPO_HCHO_L3` and `TEMPO_NO2_L3`, V04).

The [README](https://github.com/virtual-zarr/tempo-virtual-zarr-pipeline#readme)
covers deploying and operating the pipeline. The [Reference](reference/architecture.md)
section holds the architecture notes, alarm documentation, and runbooks.
